# Shamsi (Jalali) occasions file
# =================================
#
# This is the source of "today's occasions" for the Telegram bot -- no
# online API is used. Pre-populated with ~240 occasions (national days,
# historical anniversaries, and religious observances) compiled from
# public Persian-calendar datasets. Edit freely: add, remove, or correct
# entries by hand. One entry per line.
#
# FORMAT:
#   DATE|FLAG|Description text
#
# DATE can be:
#   MM/DD          -> recurs every Shamsi year on this month/day.
#                      Use for fixed-date occasions: Nowruz, national
#                      days, historical anniversaries, birthdays, etc.
#   YYYY/MM/DD     -> applies only in that one specific Shamsi year.
#                      Rarely needed -- mainly for a one-off event you
#                      want reminders for.
#   G:MM/DD        -> recurs every year on this Gregorian month/day.
#                      Use for international observance days (these are
#                      fixed on the Gregorian calendar, not the Shamsi
#                      one, so they'd drift by a day every 4 years if
#                      entered as a Shamsi date instead).
#   H:MM/DD        -> recurs every year on this Hijri (lunar) month/day.
#                      Use for religious occasions (Ramadan, Eid, Ashura,
#                      etc.). The script converts "today" to the Hijri
#                      calendar automatically at runtime, so these land
#                      on the correct Shamsi date every year with NO
#                      manual updating needed -- unlike the Shamsi
#                      calendar, the Hijri date for these does NOT shift
#                      year to year relative to itself.
#                      Hijri months: 1 Muharram, 2 Safar, 3 Rabi al-Awwal,
#                      4 Rabi al-Thani, 5 Jumada al-Awwal, 6 Jumada
#                      al-Thani, 7 Rajab, 8 Sha'ban, 9 Ramadan, 10 Shawwal,
#                      11 Dhu al-Qi'dah, 12 Dhu al-Hijjah.
#
# FLAG is either:
#   H              -> official holiday (shown with a red marker)
#   -              -> occasion / notable day, not an official holiday
#
# Lines starting with # are comments and are ignored. Blank lines are
# ignored too. You can have multiple entries for the same date.
#
# Note on accuracy: Hijri-to-Gregorian/Shamsi conversion is done
# arithmetically (the widely-used tabular Islamic calendar) and can be
# off by a day from Iran's officially announced dates in a given year,
# since those are set by moon-sighting committees. For exact official
# dates in a given year, cross-check against time.ir close to the date.
#
# -----------------------------------------------------------------------
